一. Numpy ndarray：多维数组对象

初识Numpy

array([[-1.05924132,  0.26077137,  1.26714743],
       [ 0.45128776, -1.00048203,  0.10035164]])

       [ 0.90257553, -2.00096406,  0.20070328]])

一个ndarray中的元素都是同一类型的，每一个数组都有shape属性和dtype属性

  • shape：用来表示数组为维度数量
  • dtype：用来表示数组元素的数据类型
(2, 3)

dtype('float64')

1.生成ndrray

数组的生成函数：

  • array 将输入数据转换为ndarray
  • asarray 将输入转换为ndarray
  • arange python内置函数arange的numpy版
  • ones 生成一定形状和数据类型的全1数组
  • ones_like 生成与给定数组同形的全1数组
  • zeros 生成一定形状和数据类型的全0数组
  • zeros_like
  • empty 生成一个没有初始化数值的空数组
  • empty_like
  • full 生成一定形状和数据类型的指定数值的数组
  • full_like
  • eye, identity（生成一个方阵，对角线为1，其他全为0）

2.ndarray数据类型

常见ndarray数据类型（不全）

  • int32 32位整数
  • int64 64位整数
  • float32 单精度浮点数
  • float64 双精度浮点数
  • bool 布尔值
  • string_ 字符串

转换数据类型的方法：astype()
